## Maintaining the archive

Keep the timestamped filenames when possible. If a screenshot is renamed, added, or removed, update this inventory and any references to it. Add descriptions when context beyond the filename would help readers.

Before sharing or retaining an image, inspect it for personal details, account information, notifications, location clues, or other sensitive content. Confirm you have permission to archive and distribute it; redact details or omit the image when appropriate. A timestamped filename does not make screenshot contents anonymous.
